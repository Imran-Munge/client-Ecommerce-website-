# ShopSphere — E-commerce Website

ShopSphere is a storefront website concept with a warm visual theme, editorial-style typography, and a responsive shopping interface.

## Built with

- HTML
- Tailwind CSS via CDN
- Inter and Playfair Display web fonts
- Font Awesome icons

## Run locally

This project uses browser-native web technologies. Clone the repository and open `index.html` in a browser, or serve the project directory with a local static HTTP server.

```bash
git clone https://github.com/Imran-Munge/client-Ecommerce-website-.git
cd client-Ecommerce-website-
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Notes

The page currently loads Tailwind CSS and fonts from external CDNs, so an internet connection is needed for those assets. Review the source before connecting payment providers or using real customer data.
